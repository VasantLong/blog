  <h2>About</h2>
  <p>
    I'm an undergrad in Information Management &amp; Information Systems, starting a master's in Software Engineering in autumn 2027. I'm still working out what to commit to — by trying things rather than planning them, and agents have made that kind of trial and error a lot cheaper.
  </p>
  <p>
    The work splits in two. Contest work was algorithms: fault detection, multi-objective routing, market segmentation. Coursework was systems: a Minesweeper clone, a gradebook, a campus information system. These days the focus is agents — I use one daily and try to put something back: writing pi extensions, filing issues and PRs against the ones I rely on.
  </p>
  <p>
    <strong>Now:</strong> pi as my main agent · attempting work-life balance · tinkering with minihub
  </p>
  <h2>What I keep running</h2>
  <ul>
    <li>
      <strong>pi ecosystem</strong> — my own extensions: a status bar, completion notifications, and a Feishu bridge so I can drive an agent from my phone. I also file issues and PRs against the ones I use.
    </li>
    <li>
      <strong>minihub</strong> — one Ubuntu box pulling server duty: Tailscale mesh, self-hosted Gitea, Immich photo sync, Zotero attachments over WebDAV, MinIO object storage. restic handles backups, and I've restored from them once on purpose.
    </li>
    <li>
      <strong>config sync</strong> — a Gitea repo as the source of truth; each machine keeps its own overrides and pulls on a timer.
    </li>
  </ul>
